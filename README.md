# 委員会議事録メーカー

一般社団法人福山青年会議所 2027年度 委員会議事録を、1-6委員会議事録フォーマットに沿った Word（.docx）で作るためのツールです。

- `index.html` 1ファイルだけで動きます（サーバー不要）。
- 委員会設定（メンバー名簿）と入力内容は、各自のブラウザ内にだけ保存されます。このリポジトリには個人名は含まれません。
- 「AIへの指示文を出す」で、録音データから読み込み用JSONを作る指示文をコピーできます。
- 「Wordを作成（zip）」で、Wordと読み込み用JSONをまとめたzipを保存します。

## 公開（GitHub Pages）
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にすると、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。
